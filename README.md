# Anip在线观影 (Anime-Repo)

一个纯前端、零依赖的 HLS 番剧在线播放器。通过 JSON 数据文件管理番剧与剧集信息，基于 [hls.js](https://github.com/video-dev/hls.js) 直接播放 `.m3u8` 流媒体，可部署到任意静态托管平台（GitHub Pages、Gitee Pages、Vercel 等）即可使用。

## ✨ 功能特性

- **访问验证**：进入站点需输入访问密码，支持多个密码（在 `index.html` 的 `LOGIN_PWDS` 中维护），会话期间免重复登录
- **HLS 在线播放**：基于 hls.js 播放 `.m3u8` 视频流，Web Worker 多线程解码
- **原生回退**：在支持原生 HLS 的浏览器（如 Safari）中自动回退到 `<video>` 原生播放
- **剧集列表**：从 `index.json` 加载仓库内全部番剧，支持按「电影 / 剧集 / 动漫」分类与关键词实时筛选（分类可组合关键词）
- **完整列表浏览**：剧集列表一次渲染全部内容，鼠标滚轮浏览，无分页
- **URL 直达**：通过 `?json=<路径>` 参数直接加载指定番剧 JSON，便于分享与收藏
- **播放器顶部标题**：当前番剧名称以渐变遮罩显示在播放器顶部
- **播放列表等高**：右侧播放列表高度与 16:9 播放器自动保持一致，切集自动滚动定位
- **播放进度记忆**：通过 `localStorage` 自动记录每部番剧上次观看的集数，刷新后自动续播
- **播放历史**：自动记录观看历史（最多 20 条），支持单条删除与一键清空；点击历史可从上次集数、上次播放位置（秒级）继续播放
- **窗口内全屏**：一键将视频在当前浏览器窗口内最大化播放（等比放大、不调用系统全屏 API），再次点击或保持布局恢复
- **缓存速度显示**：播放器右下角实时显示当前缓存下载速度（KB/s、MB/s 自适应，无下载时归零）
- **积极缓存策略**：一次性缓存整个视频（分片持续下载至片尾），播放中不再因缓冲不足卡顿；对源站分片时间线空洞放宽容错（`maxBufferHole`），网络/媒体错误自动重连与恢复，并在页面显示具体错误
- **键盘快进快退**：`←` 后退 5 秒 / `→` 前进 5 秒（输入框内不误触）
- **响应式布局**：自适应 PC 与移动设备；移动端播放时播放器吸顶固定，不随页面滚动
- **深色主题**：简洁的暗色 UI，聚焦观看体验

## 📁 项目结构

```
Anime-Repo/
├── index.html            # 单页播放器（HTML + CSS + 业务逻辑）
├── index.json            # 番剧清单索引（仓库内全部番剧，含分类）
├── episodes/             # 番剧剧集数据目录
│   ├── 模板.json         # 剧集 JSON 数据格式模板
│   ├── tt13293588.json   # 示例：无职转生 Part.1（24 集）
│   └── tt15553038.json   # 示例：无职转生 Part.2（12 集）
└── static/
    └── hls.min.js        # hls.js 库（已本地化，离线可用）
```

## 🚀 快速开始

### 本地预览

由于页面使用相对路径请求 `/index.json` 与 `/static/hls.min.js`，建议通过本地静态服务器访问：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js（需全局安装 serve）
npx serve -l 8080

# 方式三：VS Code 的 Live Server 插件
```

然后浏览器打开 `http://localhost:8080`。

### 部署到 GitHub Pages

1. 将仓库推送到 GitHub
2. 进入仓库 **Settings → Pages**，将部署源选择为 `main` 分支的根目录
3. 访问 `https://<用户名>.github.io/Anime-Repo/` 即可

> 如需部署到子路径（如 `https://<用户名>.github.io/Anime-Repo/`），页面内资源请求均以仓库根为基准的绝对路径编写，可直接工作。

## 📄 数据格式说明

### 番剧清单 `index.json`

数组结构，每项包含番剧标题、分类与对应的剧集数据文件路径：

```json
[
  {
    "title": "无职转生：到了异世界就拿出真本事 (2021)",
    "type": "动漫",
    "jsonFile": "episodes/tt13293588.json"
  },
  {
    "title": "逃出绝命街 The End of Oak Street (2026)",
    "type": "电影",
    "jsonFile": "episodes/tt27165187.json"
  }
]
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | string | 番剧显示名称 |
| `type` | string | 分类：`电影` / `剧集` / `动漫`（缺省时按动漫处理） |
| `jsonFile` | string | 剧集数据 JSON 的仓库相对路径 |

### 剧集数据 `episodes/*.json`

包含番剧标题、分类与剧集数组，每集由标题和 `.m3u8` 流地址组成（格式参考 `episodes/模板.json`）：

```json
{
  "title": "番剧名称",
  "type": "动漫",
  "episodes": [
    { "title": "第01集", "src": "https://example.com/xxx/index.m3u8" },
    { "title": "第02集", "src": "https://example.com/xxx/index.m3u8" }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | string | 番剧名称（页面顶部展示） |
| `type` | string | 分类：`电影` / `剧集` / `动漫`，与清单索引保持一致 |
| `episodes` | array | 剧集列表，按数组顺序播放 |
| `episodes[].title` | string | 集数标题（如"第01集"） |
| `episodes[].src` | string | 该集 HLS 播放地址（`.m3u8`） |

## ➕ 如何添加新番剧

1. 在 `episodes/` 目录下新建 JSON 文件（建议以番剧标识命名，如 `tt12345678.json`），按上方模板填入标题、分类与各集 `.m3u8` 地址
2. 在 `index.json` 数组中追加一项，写入番剧标题、分类 `type`（`电影` / `剧集` / `动漫`）与 `jsonFile` 路径
3. 提交并推送，刷新页面即可在"剧集列表"中看到并播放

## 🎮 使用说明

- **访问验证**：首次进入需输入访问密码（密码在代码 `LOGIN_PWDS` 中配置，支持多个），会话期间免重复输入
- **URL 参数**：`?json=episodes/tt13293588.json` 可直达指定番剧，适合跨设备分享（播放进度记忆的 key 即该参数）
- **切换番剧**：页面底部"剧集列表"中按分类或关键词筛选，点击任意卡片
- **播放历史**：页面底部"播放历史"区块可查看记录，点击续播；每条记录可单独删除（✕），支持一键清空全部
- **快捷键**：`←` 后退 5 秒、`→` 前进 5 秒
- **窗口全屏**：点击播放器右上角"窗口全屏"在当前浏览器窗口内最大化视频，再次点击退出
- **进度记忆**：每部番剧的观看进度（集数 + 集内播放位置）自动保存在浏览器 `localStorage`，再次打开自动续播
